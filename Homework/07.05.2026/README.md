## Structure Overview

### Titanic Survival Calculator

This project predicts a passenger's death risk using Titanic dataset.
The user enters name, sex, age, and fare, then the app classifies the passenger class by comparing fare to class medians and applying an upgrade rule when fare is high enough. A unique ticket number is generated, passenger ticket is saved to a text file, and survival probability is calculated from historical data. The menu supports adding passengers and viewing recent or all passengers in the current session.
